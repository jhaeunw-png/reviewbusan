# 분석 파생변수

## 군집분석

| 파생변수          | 계산식                                                               |
| ----------------- | -------------------------------------------------------------------- |
| `관심관광비율(%)` | `관심관광지수 ÷ 관광지수 × 100`                                      |
| `1인당관광소비`   | `총소비액 ÷ 방문자수`                                                |
| `평균숙박자비율`  | 구군별 월별 `숙박자 비율(%)`의 산술평균                              |
| `정류장공급도`    | `정류장수 ÷ 면적(km²)`. 분모는 `sigungu.area_km2`, 단위는 정류장/km² |

## 회귀분석

| 파생변수                  | 계산식                                                                    |
| ------------------------- | ------------------------------------------------------------------------- |
| `예측대상월_관광방문자수` | `예측대상월_외지인방문자수 + 예측대상월_외국인방문자수`                   |
| `전월_관광방문자수`       | `전월_외지인방문자수 + 전월_외국인방문자수`                               |
| `관광방문자_성장률(%)`    | `(예측대상월_관광방문자수 - 전월_관광방문자수) ÷ 전월_관광방문자수 × 100` |

전월 관광방문자수가 0이면 성장률을 계산할 수 없다.
